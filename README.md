# Mi Consumo

App web (PWA) para registrar las cargas de combustible del auto y seguir su consumo.

- Ubica la estación por GPS (base de la Secretaría de Energía, ~5.300 estaciones)
- Registra litros, importe y kilometraje en 3 pasos
- Calcula km/l con el método tanque lleno a tanque lleno
- Gráficos de consumo y gasto por mes
- Funciona sin conexión; los datos quedan en el teléfono

Usar la app: https://tydra-hq.github.io/consumo/

## Logos
Los logos de las marcas vienen de Wikimedia Commons (lista en `logos/fuentes.json`) y se usan solo para identificar cada estación. Son marcas registradas de sus respectivos dueños; la app no está asociada a ninguna petrolera.
